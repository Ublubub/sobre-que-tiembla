# ¿Sobre qué tiembla?

Resumen público de la investigación del póster L. HTML estático, sin dependencias.

Regenerar desde la raíz: `python scripts/build_investigation_page.py` (requiere el PDF ya compilado en `posters/out/`).

Publicación: rama `gh-pages`, directorio raíz, en GitHub Pages. El PDF original se conserva sin cambios; el resumen precisa la interpretación de la participación energética del Pacífico.
