# ¿Sobre qué tiembla?

Resumen público de la investigación del póster SIECOM 2026. HTML estático, sin dependencias.

Regenerar desde la raíz: `python scripts/build_investigation_page.py` (requiere el PDF ya compilado en `posters/out/`).

Publicación: rama `gh-pages`, directorio raíz, en GitHub Pages. El PDF se publica como `Poster_SIECOM_2026.pdf` y su contenido se conserva sin cambios; el resumen precisa la interpretación de la participación energética del Pacífico.
